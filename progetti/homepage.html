Dashboard ordini

Ho sviluppato una dashboard ordini dinamica
focalizzata sulla gestione fluida dei dati tramite
JavaScript. L'interfaccia permette di consultare,
filtrare e visualizzare gli ordini in modo rapido,
integrando una logica di calcolo in tempo reale
che aggiorna il prezzo totale in base alla selezione
degli input. Ho inoltre implementato funzionalità
CRUD complete per la gestione di articoli e clienti,
garantendo un controllo totale sui dati senza necessità di ricaricare la pagina.

  • HTML
  • CSS
  • JS
  • Lucide Icons

E-commerce

Questo progetto e-commerce rappresenta
una soluzione completa per la vendita online,
dove ho curato sia l'interfaccia utente che
la logica di programmazione. Partendo da una
landing page strutturata per valorizzare i
prodotti e il team, ho sviluppato tramite
JavaScript tutte le funzionalità essenziali
del carrello, permettendo una gestione dinamica
degli articoli e un processo di checkout intuitivo.
Il risultato è una piattaforma funzionale che
trasforma la navigazione in un'esperienza d'acquisto fluida, dalla scelta della categoria al riepilogo finale dell'ordine.

  • HTML
  • CSS
  • JS
  • Lucide Icons

To Do List

Web app reattiva per la gestione dei task
giornalieri, sviluppata in React.
L'applicazione include un sistema
di monitoraggio dello stato che aggiorna
in tempo reale il contatore dei task
(totali, completati e da fare).
Dispone di un'interfaccia utente pulita
che permette l'aggiunta e l'eliminazione
rapida delle attività tramite comandi intuitivi.

  • React
  • CSS
  • Lucide Icons

Trello Clone

Un'applicazione web Trello clone interattiva
sviluppata in React per organizzare il lavoro
tramite liste e schede dinamiche. L'utente può
creare nuove liste, aggiungere task, contrassegnarli
come completati ed eliminarli in tempo reale con
un'interfaccia reattiva. Dal punto di vista tecnico,
il progetto adotta un'architettura a componenti
modulari e sfrutta l'hook useState per
gestire lo stato dinamico e l'immutabilità dei
dati durante tutte le operazioni di gestione dei contenuti

  • React
  • CSS
  • Lucide Icons
  • Google Fonts
